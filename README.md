# Subrogation Recovery Engine

A multi-agent system for property and casualty insurers. It looks for money left on the table in subrogation: claims that can still be recovered from the party who should have paid.

The engine is meant to:

- Find claims that are still recoverable
- Build the case from the claim file
- Draft the demand
- Hold the draft behind a confidence gate
- Keep an audit trail of what was decided and why

## Status

This repository is the project home. It currently contains the MIT license and this README. The recovery workflow above is the product intent; the agent pipeline is not in this repository yet.
